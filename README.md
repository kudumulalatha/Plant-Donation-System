# 🌱 Plant Donation System

A web-based **Plant Donation System** that connects people who want to donate plants with people who wish to grow them. The project encourages greenery, environmental awareness, and community participation.

## 🚀 Features

- 🌿 **Plant Donation:** Share plants with people who need them.
- 👤 **User Management:** Store user information and support community participation.
- 💬 **Comments:** Allow users to interact through comments.
- 🕒 **Recent Activity:** Display recent activities within the application.
- 📱 **Simple Interface:** Easy-to-use interface for browsing plant donations.
- 💾 **Local Storage:** Store supported application data in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
